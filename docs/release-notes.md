# Navet Cards 0.1.0-beta.3

Room-first composition and efficient dashboard updates for Home Assistant.

- Open lazy room panels with supported inline controls and named hash navigation.
- Add compact row layouts, entity sub-controls and declarative state conditions.
- Use number and select cards with native bounds, steps and options.
- Adjust supported heating modes, media skip/mute/sources and light color temperature.
- Configure areas, entities and actions with HA selectors, appearance presets and low/high effects.
- Keep room membership indexed across unrelated state updates and release closed panel content.
- Use a visible climate target slider and keyboard/touch step controls.

This build is prepared for human verification. The [verification status](verification-status.md) records tested surfaces and remaining household, low-power client, companion-app and HACS gates. The maintainer approves prerelease publication after reviewing the evidence.
