# Private beta verification status

Build: **0.1.0-beta.2**. Verification date: **2026-10-04**.

The beta is prepared for maintainer verification by manual installation. A real Home Assistant backend with demo integrations provides integration evidence; it does not establish behavior for every physical device or companion app.

Existing contract and browser tests are **Keep**: they cover public behavior, realistic capability payloads, interactions, configuration preservation, and regressions. Added permission tests cover direct and wrapped HA WebSocket unauthorized errors. Added presentation regressions cover keyboard brightness presets, temperature steps, cover position commands, broken artwork fallback, and the compact media volume popover; normalized metadata tests cover malformed artwork URLs. The separate live test is opt-in and uses only sessions generated by the disposable validation setup.

## Maintainer acceptance gates

- Real household-device capability combinations, permission/transport failures, reconnection, and registry changes.
- Companion-app WebViews, touch gestures, keyboard/focus, reduced motion, and household browser coverage.
- Repeated editing of advanced YAML, chosen dashboard dimensions, Fahrenheit temperature ranges, and coexistence with Bubble Card.
- Household installation, cache refresh on each frontend, upgrade, and rollback.
- Public HACS clean install and upgrade after publication is authorized; catalog submission is separate.

These gates are intentionally part of the [human verification handoff](human-verification.md). Final visual acceptance belongs to the maintainer. This scoped Lovelace implementation uses Home Assistant details for light color/effects and richer media settings; the Storybook references guide presentation without establishing complete feature parity. A successful private beta check is not a public stable-release claim.
